온결 v0.7 Cloudflare Pages 업로드 폴더

1. 먼저 supabase.com 에서 프로젝트를 만들고 별도 ZIP의 SQL 파일을 SQL Editor에서 실행합니다.
2. 이 폴더의 config.js에서 supabaseUrl, supabasePublishableKey만 수정합니다.
3. 이 web 폴더의 파일들이 Pages 루트에 오도록 업로드합니다. index.html이 최상위여야 합니다.
4. 별도 docs/SETUP_KO.md에 전체 설명이 있습니다.

이 ZIP/폴더에 secret key/service_role/DB password를 넣지 마세요.
