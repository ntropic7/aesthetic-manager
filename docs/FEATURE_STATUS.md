# 온결 기능 범위 v0.7

| 기능 | 이번 연결판 상태 |
|---|---|
| 이메일 회원가입/로그인·로그아웃 | **구현** (Supabase Auth, 인증 메일 확인) |
| 새 매장 생성·매장 구분 | **구현** (RLS, shop membership) |
| 원장 직원 초대코드 | **구현(파일럿)**. 상세 역할별 데이터 권한 미구현, 실고객 운영 전 제한 |
| 매장정보·프로그램·관리사·관리실 | **구현** (앱 UI + 서버 JSON 상태) |
| 고객 등록/검색/고객 360 | **구현** (v0.6 누락 고객 등록 저장 함수 보완) |
| 예약 일간·주간(관리사별)·목록 | **유지** (0.12~1.25 축소, 모바일 주간) |
| 예약 드래그/길이조절·편집·노쇼·취소·복원 | **유지**, 최신 상태에서 충돌검사 후 서버 저장 |
| 상담 내용/기록/AI 제안 선택 승인 | **규칙 기반 분석만 유지**, LLM 실제 분석은 미연결 |
| 녹음 파일 | 기기 다운로드, STT API 미연결 |
| 고객 전후사진 | **비공개 Supabase Storage 업로드/임시 링크** |
| 관리완료·횟수권 차감/복원·결제기록 | **유지**, 저장 충돌 감지 (서버 측 개별 트랜잭션 아직 없음) |
| 차량·주차·대기예약·직원휴무·재고·운영 할 일 | **유지**, 서버 저장 |
| 예약톡 초안·캠페인 시뮬레이션 | **유지**, **실제 발송 안 함** |
| 마케팅 세그먼트·수동 노출 스냅샷·매출 집계 | **유지**, 외부 검색 자동 수집 안 함 |
| 무료 웹/PWA 인터넷 배포 | **배포 파일 완성**, Cloudflare 업로드는 사용자 계정 필요 |
| 동시 수정 충돌 감지 | **구현**, 자동 병합 아님 |
| 직원 세분화 권한/SQL 정규화·DB 트랜잭션 | **미구현(상용화 필수)** |
| 안드로이드 APK/AAB·iOS IPA·스토어 배포 | **미구현(차기 단계)** |
