**직원 등록 고지 3상태:** `미확인` → `매장 관리자 고지확인(관리자 진술)` → `직원 본인 계정 직접 확인`. 첫 번째/두 번째는 직원 본인 동의의 증거가 아니다.

**증빙 필드:** shop_id, actor_user_id, subject_kind, subject_ref, purpose, lawful_basis, document_version, event_action, evidence_method, evidence_reference, acted_at, attestation_only. 증빙 원문은 원칙적으로 DB JSON 문자열에 복사하지 말고 권한이 제한된 별도 보관소에 저장.
