# 온결 매니저 v0.9.1 — 명칭·업종 일반화 변경 기록

## 이름 규칙

- 앱스토어/브라우저/PWA/로그인: **온결 매니저**
- 로그인 후 사이드바·대시보드·상단 경로: 사용자가 등록한 **매장 브랜드명**
- 개발 프로젝트·Cloudflare 프로젝트 slug: `aesthetic-manager` (유지)
- DB / 기존 RPC / API 설정 변수: 이름 변경 없음. SQL 실행 불필요

## 사용자 인터페이스 용어

| 기존 화면 표현 | 변경된 기본 표현 | 기존 기능 |
|---|---|---|
| 피부관리샵 운영 | 예약 기반 매장 통합관리 | 로그인·온보딩 유지 |
| 관리 프로그램 | 서비스/프로그램 | 예약·메뉴 가격/시간 유지 |
| 관리사 | 담당 직원 | 담당자 배정/휴무/주간 일정 유지 |
| 관리실·베드 | 공간·좌석 | 충돌 방지·공간 배정 유지 |
| 관리 완료 / 관리이력 | 서비스 완료 / 서비스 이력 | 완료 처리·회원권 차감/복원 유지 |
| 피부 프로필 | 고객 특성·선호 프로필 | 기존 입력 필드 보존 |

## 범용화 한계

- `type`, `pressure`, `concerns`, `before`, `after` 등 DB/JSON 필드는 기존과 호환되도록 변경하지 않았습니다.
- 피부/알레르기 관련 세부 입력과 녹음·사진 기능은 삭제하지 않았습니다. 타 업종에서는 필요할 때만 입력합니다.
- 업종 선택 및 업종별 필드 템플릿 활성화는 **아직 구현하지 않았습니다**. 기본 화면 문구만 먼저 일반화한 버전입니다.
- AI 상담 분석은 여전히 샘플 키워드 규칙 기반이며 실제 LLM 연동 전입니다. 모든 업종에서 동등하게 분석 가능한 기능으로 주장하지 않습니다.
- 기존 JSON 업무 저장 구조, 세부 권한 제한, 외부 메시지·검색 API 미연결 상태는 이전 버전과 동일합니다.
