# v1.0 변경 명세

- 설정 화면: 매장 → 직원·직책(동일 패널) → 서비스/프로그램 → 매장 연결 승인 → 백업 → 외부 연동.
- 매장 연결 코드 생성·재발급, 직원의 연결 요청 및 관리자 승인, 계정별 권한 별도.
- 신규 매장 시 직원 1명 필수, 직책 선택, 관리자계정과 직원 연결 선택.
- 직원 삭제 차단: 최소1명, 로그인 연결, 예약·서비스 이력 등 참조 관계. 이관은 서버 트랜잭션으로 처리.
- 시간표: 고정 스크롤 창 내부 축척 변경, 하루 전체 표시 + 8단계 확대. 주간 열/일간 열 수 변경하지 않음.
- PostgreSQL RPC 마이그레이션: `004_shop_join_approval_and_staff_integrity.sql`.
- v0.9.x 저장데이터는 삭제하지 않고, 호환용 `ongeol_` 식별자 유지.
- 다른 업무 기능(상담 AI 모의 분석, 예약톡 초안, 회원권, 결제, 주차, 재고, 마케팅)은 그대로 유지.
